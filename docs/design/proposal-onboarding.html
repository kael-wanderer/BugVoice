Onboarding

Three parts: (1) install help inside the DMG, (2) a first-launch onboarding window, (3) a 6-stop tour of the main window. The built-in cleanup model sits inside step 5 of the onboarding. Model names and sizes are placeholders until the bench picks them.

DMG→1 Welcome→2 Hotkey→3 Permissions→4 Speech model→5 Cleanup→6 Try it→7 Tour or start

Part 1. The DMG window

Today the DMG shows the app and an Applications shortcut, nothing else. New: a background image with the drag arrow and, below it, the two ways past the "Not Opened" block. Way A comes first because it needs no Terminal. The DMG also carries a Read Me First.pdf with the same steps and screenshots.

2. Open BugVoice. If macOS says "BugVoice Not Opened", use one of these:

Way A: System Settings Easiest

  1. Click Done on the message.
  2. Open System Settings › Privacy & Security.
  3. Scroll down, click Open Anyway next to BugVoice.
  4. Enter your Mac password.

Way B: Terminal

  1. Open Terminal.
  2. Paste and press Return:
    xattr -cr /Applications/BugVoice.app
  3. Open BugVoice again.

You only do this once. Updates through Check for Updates do the same check, so the update note keeps Way A and Way B too.

Part 2. Onboarding, step 1: Welcome

Opens on first launch, once. Every step has Back and Skip; Skip setup ends it and leaves the Readiness card to show what is missing. Reopen any time from Settings › General › Run setup again.

Welcome to BugVoice

Step 5a: Cleanup model, choose a kind

Cleanup fixes punctuation, filler words and mixed-language spelling. Built-in is first and recommended for people without LM Studio or an API key. Apple Intelligence shows only on macOS 26 Macs that have it. "Paste raw text" is a valid choice, not a failure.

Part 3. Step 7: Take the tour or start

Last onboarding step. Either choice ends setup (onboardingDone). "Take the tour" closes this window, opens the main window and starts the 6-stop tour. The tour can be run again from Settings › General and from the menu bar popover ("Take the tour").

Step 7 of 7
