Cancel while processing

After the hotkey is released, Esc stops a dictation while it is Transcribing or Cleaning. Nothing is pasted, copied or added to history. Command mode already works this way.

1. The HUD names the key

Both processing stages end with “Esc to cancel”, the same words the command-mode Rewriting pill uses.

TranscribingVietnamese · Esc to cancel
Cleaning (Qwen)Notion · Esc to cancel

Cleaning with no app name shows just “Esc to cancel”.

2. After Esc

The message shows at once and hides after 1.2 s, without waiting for Whisper or the model to stop.

Cancellednothing was pasted · Retry last runs it again
Cancellednothing was added
Cancellednothing was replaced

Once the paste has started, Esc no longer stops it. Esc during a hold recording already cancels it, as any key does. Hands-free recordings still stop only on a hotkey tap. Like command mode, Esc also reaches the app in front.
