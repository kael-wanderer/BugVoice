Shared by both options
  • Each tab is an ordinary note file (Markdown, as today); closing a tab never deletes the note.
  • Toolbar writes Markdown: heading, bold, italic, lists, checklist, quote, code, link. The editor shows it styled.
  • Transforms work on the selection, or the whole note when nothing is selected. Result is a preview; Replace is one undo step.
  • Dictation lands at the cursor of the active tab, cleaned by the Notes model.
  • Meetings and Upload get "Send to Scratchpad": the transcript or summary opens as a new tab.
A · Notes page: for
  • One editor, one place; reuses the list, autosave and dictation routing that exist.
  • Room for a wide editor and the note list.
  • Least new code.
A · Notes page: against
  • Must switch to the BugVoice window to jot something.
B · Floating window: for
  • Open over any app with a shortcut, jot or dictate, hide again.
  • Stays on top while you work in Linear, a browser or a call.
B · Floating window: against
  • A second editor for the same files: both must stay in sync.
  • Dictation must learn a second destination; a new global shortcut.
  • Narrow: formatting toolbar is compact.
