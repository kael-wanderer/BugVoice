Command mode

Spec: docs/superpowers/specs/2026-10-19-command-mode-design.md. Select text, hold Right Option, say what to change, release. The selection is replaced. With nothing selected, say what to write.

Three moments of one command. The HUD pill is the dictation pill with a Command tag; the selection size tells the user BugVoice read the selection.

2. Write new text (nothing selected)

The instruction becomes a request. The text before the cursor is sent as context so the reply fits.

Hold with no selection

Slack — #team
Lan: can you join the review at 3?
CommandNew text · Slack Auto

Said: "reply that I'll join but ten minutes late"

Written

Slack — #team
Lan: can you join the review at 3?
Yes, I'll join, but I'll be about ten minutes late.
Written11 words

Nothing is sent: BugVoice never presses Return.
