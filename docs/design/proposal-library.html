Folders and tags

One "Manage library" sheet with two tabs, opened from "Manage folders…" and a new "Manage tags…" at the bottom of the Folder and Tags filter menus (Meetings and Scratchpad pages). Folders scope what you see; tags cut across folders for quick search and metadata. Changes apply to every note and meeting. Agreed 2026-10-18: flat folders; spec docs/superpowers/specs/2026-10-18-library-management-design.md.

Where the colour shows

✦ AI🗀 Client A ⌄#client ✕#follow-up ✕＋ Add tag
⌂ Tags ⌄#client#idea
Does Markdown support tag colours? No. Markdown has no colours, and a note keeps its tags as plain names in its front matter (tags: [client, follow-up]). The colour lives in BugVoice's library.json, keyed by tag name, so note files stay clean and other apps (Obsidian, VS Code) still read the tags. The colour shows only inside BugVoice: as a dot on tag chips in the editor, the filter menu and list cards. Tag text stays the normal colour so it is readable in every theme.

How to open it

The same sheet, opened on the right tab, from wherever you pick a folder or a tag. It slides down from the top of the window you are in (a macOS sheet), centred, about 460 pt wide; Done or Escape closes it.
