Quick Pad: which note does it open?

A small window on top of other apps for speak → fix → rewrite → copy. Press ⌃⌥Space anywhere, hold Right Option to speak (or type), run Polish or More professional, then Copy as Work message and paste into Slack. Esc or copying hides the pad. The text is always saved as an ordinary Scratchpad note. The three options differ only in which note the pad shows when it opens.
