Scratchpad window

The floating window is the only Scratchpad editor. The Scratchpad page lists notes as cards. ⌃⌥N opens the window with a new note from any app; the menu bar item and a card's Edit open it too. Notes stay Markdown files; the buttons write Markdown.

Behavior

AI bar
  • Polish, More professional, More casual work on the selection, or the whole note when nothing is selected.
  • The result replaces the text in the editor at once. ⌘Z undoes it; History keeps the version before.
  • ↻ runs the last AI change again on the same original text and replaces its result.
  • The box takes anything: “shorter, add a greeting” changes the note; “what did I promise Linh?” answers above the box and leaves the note alone.
Formatting bar
  • H1 H2 · Bold Italic Underline Strikethrough Code · Bullets Numbers Checklist · Quote Indent · Link Table.
  • Every button writes Markdown. Underline is saved as <u>text</u>.
  • Table opens a grid; the chosen rows × columns insert an empty Markdown table.
  • Indent adds two spaces to list lines; ⇧-click or ⇧⇥ removes them.
Copy
  • Copy puts formatted text and plain text on the clipboard: Slack, Gmail and Notion keep bold and lists; a terminal gets plain text.
  • The ▾ menu has Copy as Markdown, Copy as plain text, and Export….
  • ⌘↩ copies, closes the window and returns to the app you came from.
Window
  • Floats over other apps and full-screen apps while Keep on top is on (default).
  • Tabs and the open note come back after a restart. Hide notes collapses the side list.
  • Holding Right Option while the window is in front dictates into the note at the caret.
