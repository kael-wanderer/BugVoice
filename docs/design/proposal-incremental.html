Incremental transcription

Spec: docs/superpowers/specs/2026-10-24-incremental-transcription-design.md. While you hold the key, BugVoice cuts the recording at natural pauses and turns each finished phrase into text on the main model. On release only the last phrase is left. Phase 2 only: it is built if the Phase 1 bench passes the gate. Times on this page are examples, not measurements.

Transcribe while speaking
Turns each finished phrase into text while you talk, so long dictations paste sooner. Uses the main speech model while you hold the key. Off with the OpenAI-compatible engine.
