Upload (roadmap item 4). A new sidebar page for transcribing an audio or video file on this Mac. Use the switcher, or click through the window: drop zone, Transcribe, Open in Meetings. The result is an ordinary meeting with an Uploaded badge: the same transcript, player, Summary, Action items and export as a recorded meeting. Transcript rows are labelled Speaker. Only audio.m4a is kept; the original file is never changed. All names and figures are examples.
