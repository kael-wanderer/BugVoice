BugVoice · Insights · storage decision

Where should Insights get its numbers?

Both options show the same Insights page. They differ in what happens when dictation history gets deleted, by the retention setting or by Clear. Pick a situation below and compare the two pages. The figures are examples, not your data.

Situation

A

Separate daily totals

Each dictation also adds to insights.json: counts per day, no text.

B

Calculate from history only

Insights reads history.jsonl each time the page opens.

Option A stores
history.jsonl · unchanged, full text, follows retention
insights.json · new, numbers only, kept until Reset insights
{
  "days": {
    "2026-10-15": {
      "words": 412, "dictations": 23, "seconds": 291,
      "notes": 1, "meetings": 0, "meetingMinutes": 0,
      "apps":   { "Ghostty": 210, "Code": 120, "Notion": 82 },
      "styles": { "terminal": 210, "other": 120, "document": 82 },
      "wordsFixed": 37
    }
  }
}
  • + Streak, heatmap and all-time totals survive retention and Clear.
  • + Fast: one small file, about 300 bytes per day.
  • + Holds no words you said, only counts and app names.
  • − One more file to keep in step. Settings → Storage gets a Reset insights button.
  • − Starts today. Days before it existed come from history once, at first launch.
Option B stores
history.jsonl · unchanged, the only source
{"app":"Ghostty","startedAt":"2026-10-15T03:19:32Z",
 "style":"terminal","raw":"Can you do something for me?",
 "inserted":"Can you do something for me?",
 "timings":{"recording":1.49,"transcribe":3.24}}
… one line per dictation, read in full on every open
  • + No new file and nothing new to reset.
  • + Numbers always match the history list exactly.
  • − With 7- or 30-day retention, Insights shows only those days.
  • − Clear history resets the streak and every total to zero.
  • − With retention set to Don't save, Insights is always empty.
Recommendation

Option A

Insights exists to show long-term habits: streak, months of activity, all-time words. Option B loses exactly those whenever you trim history for privacy. Option A keeps the habit numbers and still drops the text. Your history is set to Forever today, so both look the same now; they differ the first time you change retention or press Clear.
