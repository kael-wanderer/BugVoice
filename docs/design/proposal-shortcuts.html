Shortcuts support

Spec: docs/superpowers/specs/2026-10-19-shortcuts-design.md. Six BugVoice actions in the Shortcuts app; three of them also in Spotlight and Siri. Everything runs from the menu bar app, offline unless you chose a remote model.

1. BugVoice in the Shortcuts library

●
Start meeting recording
Starts recording a meeting, like Start meeting in the menu bar. Optional title.
■
Stop meeting recording
Stops the meeting that is recording. Transcription continues in BugVoice.
♪
Transcribe audio file
Transcribes an audio file on this Mac and returns the transcript. The recording is kept in Meetings.
✎
Rewrite text
Applies an instruction to text with your Dictation cleanup model, like command mode.
+
New note
Creates a Scratchpad note with the text. Optional title and folder.
✓
Get open action items
Returns open action items from your meetings, newest meeting first.

2. Example shortcut: voice memo to note

Chains three BugVoice actions. Could run from a folder automation, a menu bar button or "Hey Siri".

⌂Get latest Voice Memo
♪Transcribe Voice Memo with BugVoice
Language: Auto · Wait for transcript: On
✎Rewrite Transcript
Instruction: turn this into a short daily log entry with bullet points
+New note with Rewritten text
Title: Daily log · Folder: Personal

3. Spotlight and Siri (App Shortcuts)

start a meeting
●Start a meeting in BugVoiceApp Shortcut
■Stop the meeting in BugVoiceApp Shortcut
+New BugVoice noteApp Shortcut

Available right after install, no setup. Siri phrases: "Start a meeting in BugVoice", "Start recording a meeting in BugVoice", "Stop the meeting in BugVoice", "New BugVoice note".

4. Errors in Shortcuts

Rewrite text
Command mode needs a text model — choose one in Settings › Models
Stop meeting recording
No meeting is recording.
Transcribe audio file
Still transcribing after 30 minutes. The transcript will finish in BugVoice › Meetings.
New note
No folder named “Wrok”.
