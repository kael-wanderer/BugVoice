Cleanup fidelity check

Spec: docs/superpowers/specs/2026-10-24-cleanup-fidelity-design.md. After cleanup, BugVoice compares the cleaned text with what you said. If a number, a "not", a path or a code name changed, the raw text pastes instead and the pill says what changed. ⌃⌥R swaps to the cleaned version.

1. Cleanup dropped "not": raw text pastes

Default setting, Paste raw text. The raw text has filler words but keeps what you said. Nothing else changes about the paste.

2. Pill wording

Shown for 4 seconds, like other warnings. The title names the first issue; two or more issues say how many. The key letter follows Settings › Shortcuts.

!Raw — cleanup changed a number⌃⌥R pastes the cleaned text !Raw — cleanup changed a path⌃⌥R pastes the cleaned text !Raw — cleanup changed a name⌃⌥R pastes the cleaned text !Raw — cleanup changed 2 details⌃⌥R pastes the cleaned text !Check — cleanup changed a number⌃⌥R pastes raw ✓Replaced with cleaned text

"Check" is the Paste cleaned text and warn setting. The last pill follows ⌃⌥R after a fallback; pressing again swaps back to raw.
