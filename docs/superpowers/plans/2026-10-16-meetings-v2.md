# Meetings v2 (5a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Offer to record when a meeting starts, and replace the recorder panel with a meeting window docked to the right third of the screen: My notes, live Transcript and a live Summary, Ask anything about this meeting, and a final summary after Stop that follows the notes.

**Architecture:** Decisions live in `VoiceCore` (TDD): new settings and manifest fields, `MeetingDetector` (which app's microphone use is a meeting), `LiveSummaryPlanner` and `MeetingQuestion` (when to refresh and what to send), and notes in the summary request and the Markdown export. `BugVoiceMac` reads the Core Audio process list. The app polls that list every 2 s for the popup, hosts the window in a non-activating `NSPanel` (the Scratchpad window pattern), and runs the live summary and Ask through the Meetings model.

**Tech Stack:** Swift 6.4 (tools 6.0), SwiftUI/AppKit, Core Audio, Swift Testing (`import Testing`), macOS 15 floor.

**Spec:** `docs/superpowers/specs/2026-10-16-meetings-v2-design.md`. Mockup: `docs/design/proposal-meeting-window-final.html` (open in a browser; light and dark). Read both before starting. Task 10 updates the spec where the build differs from it (polling, frame autosave, click-to-edit title).

## Review Focus

1. A browser tab that uses the microphone without a meeting title (a voice recorder site, a dictation extension) — no popup. Pinned by `browserCountsOnlyWithAMeetingTitle` (Task 2).
2. The meeting app drops the microphone for a few seconds (mute toggle, device switch) — no Meeting ended until 10 quiet seconds, and only for the app that started the recording. Pinned by `endedWaitsWhenTheAppComesBack` and `otherAppsNeverEndARecording` (Task 2).
3. A long meeting whose new lines do not fit the model's context — the oldest new lines are dropped and the cutoff still moves past all of them, so the next refresh does not resend them. Pinned by `oversizeNewLinesKeepTheNewestAndCutoffCoversAll` (Task 3).
4. Typing notes and pressing Stop (or quitting) within the 1-second save delay — the notes are flushed before Stop, Cancel and Stop-and-keep (`flushNotes`, Task 7). Saving after Stop is allowed by `MeetingSession.acceptsNotes` (pinned in Task 1). Checked on the device by row 187.
5. Clicking Mark, Pause, the tabs or Collapse while the meeting app has the keyboard — the keyboard stays with the meeting app. The panel uses `becomesKeyOnlyIfNeeded = true` and the title is a label until clicked, so no text field takes the keyboard when the window shows (Task 7). Checked on the device by row 178.

import Foundation

/// One process that Core Audio lists, with what BugVoice needs to decide
/// whether it is in a meeting.
public struct AudioInputProcess: Equatable, Sendable {
    public var pid: Int32
    public var bundleID: String
    public var isRunningInput: Bool
    /// Window titles of the app; filled only for browsers.
    public var windowTitles: [String]

    public init(pid: Int32, bundleID: String, isRunningInput: Bool, windowTitles: [String] = []) {
        self.pid = pid
        self.bundleID = bundleID
        self.isRunningInput = isRunningInput
        self.windowTitles = windowTitles
    }
}

public struct MeetingCandidate: Equatable, Sendable {

public enum MeetingDetectionEvent: Equatable, Sendable {
    case detected(MeetingCandidate)
    case ended(bundleID: String)
}

/// Decides from microphone use when to offer to record a meeting and when
/// to offer to stop. It never starts or stops anything itself.
public struct MeetingDetector: Sendable {
    public static let meetingApps: [String: String] = [
        "us.zoom.xos": "Zoom",
        "com.microsoft.teams2": "Microsoft Teams",
        "com.microsoft.teams": "Microsoft Teams",
        "com.tinyspeck.slackmacgap": "Slack",
        "com.apple.FaceTime": "FaceTime",
        "Cisco-Systems.Spark": "Webex",
        "com.hnc.Discord": "Discord",
    ]
    public static let browsers: [String: String] = [
        "com.google.Chrome": "Google Chrome",
        "com.apple.Safari": "Safari",
        "company.thebrowser.Browser": "Arc",
        "com.microsoft.edgemac": "Microsoft Edge",
        "org.mozilla.firefox": "Firefox",
        "com.brave.Browser": "Brave",
    ]
    /// Seconds the recorded app must stay off the microphone before "Meeting ended".
    public static let endDelay: TimeInterval = 10

    private let ownPID: Int32
    /// Apps already offered while they kept using the microphone.
    private var offered: Set<String> = []
    private var quietSince: Date?
    private var endedSent = false

    public init(ownPID: Int32) {
        self.ownPID = ownPID
    }

    /// The app a bundle ID belongs to: itself, or the app whose ID it extends
    /// (`com.google.Chrome.helper` belongs to `com.google.Chrome`;
    /// `com.apple.WebKit.GPU` to Safari). Nil when unknown.
    public static func appBundleID(for bundleID: String) -> String? {
        // Safari records the microphone in WebKit's GPU process.
        if bundleID == "com.apple.WebKit.GPU" { return "com.apple.Safari" }
        for known in Array(meetingApps.keys) + Array(browsers.keys)
        where bundleID == known || bundleID.hasPrefix(known + ".") {
            return known
        }
        return nil
    }

    /// Feed the current process list. Call on every change and at least every
    /// 2 seconds while recording so "Meeting ended" can fire.
    public mutating func update(
        processes: [AudioInputProcess],
        now: Date,
        isRecording: Bool,
        recordingApp: String?,
        muted: Set<String>
    ) -> [MeetingDetectionEvent] {
        var active: [String: MeetingCandidate] = [:]
        var order: [String] = []
        for process in processes where process.pid != ownPID && process.isRunningInput {
            guard let app = Self.appBundleID(for: process.bundleID), active[app] == nil,
                  let candidate = Self.candidate(app: app, windowTitles: process.windowTitles) else { continue }
            active[app] = candidate
            order.append(app)
        }
        offered.formIntersection(active.keys)

        var events: [MeetingDetectionEvent] = []
        if isRecording {
            offered.formUnion(active.keys)
            if let recordingApp {
                if active[recordingApp] != nil {
                    quietSince = nil
                    endedSent = false
                } else {
                    let since = quietSince ?? now
                    quietSince = since
                    if !endedSent, now.timeIntervalSince(since) >= Self.endDelay {
                        endedSent = true
                        events.append(.ended(bundleID: recordingApp))
                    }
                }
            }
        } else {
            quietSince = nil
            endedSent = false
            if let app = order.first(where: { !offered.contains($0) && !muted.contains($0) }), let candidate = active[app] {
                offered.insert(app)
                events.append(.detected(candidate))
            }
        }
        return events
    }

    static func candidate(app: String, windowTitles: [String]) -> MeetingCandidate? {
        if let name = meetingApps[app] {
            return MeetingCandidate(bundleID: app, appName: name, title: name)
        }
        for title in windowTitles {
            guard let service = webMeetingService(windowTitle: title) else { continue }
            return MeetingCandidate(bundleID: app, appName: service, title: meetingTitle(fromWindowTitle: title) ?? service)
        }
        return nil
    }

    /// "Google Meet", "Microsoft Teams" or "Zoom" when a browser window title is a web meeting.
    public static func webMeetingService(windowTitle: String) -> String? {
        let title = windowTitle.lowercased()
        if title.hasPrefix("meet:") || title.hasPrefix("meet - ") || title.hasPrefix("meet – ")
            || title.contains(" meet - ") || title.contains(" meet – ") {
            return "Google Meet"
        }
        if title.contains("microsoft teams") { return "Microsoft Teams" }
        if title.contains("zoom"), title.contains("meeting") { return "Zoom" }
        return nil
    }

    private static let titleNoise: Set<String> = [
        "meet", "google meet", "microsoft teams", "zoom", "google chrome", "safari", "arc",
        "microsoft edge", "microsoft​ edge", "firefox", "mozilla firefox", "brave",
        "camera or microphone recording", "microphone recording", "audio playing",
    ]

    /// "Meet - Helpdesk bot sync - Google Chrome" gives "Helpdesk bot sync". Nil when only app names are left.
    public static func meetingTitle(fromWindowTitle windowTitle: String) -> String? {
        var text = windowTitle
        if text.lowercased().hasPrefix("meet:") { text = String(text.dropFirst(5)) }
        let parts = text.split(separator: /\s[-–—|]\s/)
            .map { $0.trimmingCharacters(in: .whitespaces) }
            .filter { !$0.isEmpty && !titleNoise.contains($0.lowercased()) }
        let joined = parts.joined(separator: " - ")
        return joined.isEmpty ? nil : joined
    }
}

import Foundation

/// Transcript lines as the meeting window's prompts show them: `[m:ss] You: text`.
public enum MeetingPromptLines {
    public static func line(_ segment: MeetingSegment) -> String {
        let seconds = max(0, Int(segment.start))
        return String(format: "[%d:%02d] ", seconds / 60, seconds % 60) + "\(segment.speaker): \(segment.text)"
    }

    /// The newest lines that fit `maxCharacters`, oldest first.
    static func newest(_ segments: [MeetingSegment], maxCharacters: Int) -> [MeetingSegment] {
        var kept: [MeetingSegment] = []
        var size = 0
        for segment in segments.reversed() {
            let length = line(segment).count + 1
            if size + length > maxCharacters { break }
            kept.append(segment)
            size += length
        }
        return kept.reversed()
    }
}

/// When the meeting window refreshes its running summary, and what it sends.
public enum LiveSummaryPlanner {
    /// Active (unpaused) meeting time before the first refresh, and between refreshes.
    public static let interval: TimeInterval = 180
    /// Notes longer than this are cut before they go into a request.
    public static let maxNotesCharacters = 4_000

    public static let systemPrompt = """
    You keep a running summary of a meeting that is still going on. You get the previous summary, \
    the user's own notes and the transcript lines spoken since the previous summary. Return the whole \
    updated summary as short Markdown bullets: what was discussed, decisions, and open questions. When the \
    notes have headings, use the same headings in the same order. Use only facts from the transcript and \
    the notes. Write in the language of the transcript. Return only the summary.
    """

    /// Whether a refresh should run now.
    /// - Parameters:
    ///   - activeTime: meeting time so far, pauses excluded.
    ///   - lastRefresh: `activeTime` at the last refresh, nil before the first.
    ///   - cutoff: meeting time up to which lines are already in the summary.
    public static func isDue(
        activeTime: TimeInterval,
        lastRefresh: TimeInterval?,
        segments: [MeetingSegment],
        cutoff: TimeInterval,
        notesChanged: Bool
    ) -> Bool {
        guard activeTime >= interval, !segments.isEmpty else { return false }
        guard let lastRefresh else { return true }
        guard activeTime - lastRefresh >= interval else { return false }
        return notesChanged || segments.contains { $0.end > cutoff }
    }

    /// The request for the next refresh and the cutoff to save with its result.
    /// New lines that do not fit the budget are dropped oldest first; the cutoff
    /// then covers the lines that went in.
    public static func request(
        previous: String?,
        notes: String,
        segments: [MeetingSegment],
        cutoff: TimeInterval,
        budget: MeetingTextBudget
    ) -> (request: CleanupRequest, cutoff: TimeInterval) {
        let notesText = String(notes.trimmingCharacters(in: .whitespacesAndNewlines).prefix(maxNotesCharacters))
        let previousText = previous?.trimmingCharacters(in: .whitespacesAndNewlines) ?? ""
        let fixed = notesText.count + previousText.count + 200
        let room = max(0, budget.inputTokens * 3 - fixed)
        let fresh = segments.filter { $0.end > cutoff }.sorted { $0.start < $1.start }
        let kept = MeetingPromptLines.newest(fresh, maxCharacters: room)
        let newCutoff = max(cutoff, fresh.map(\.end).max() ?? cutoff)
        let user = """
        Previous summary:
        \(previousText.isEmpty ? "None yet" : previousText)

        My notes:
        \(notesText.isEmpty ? "None" : notesText)

        New transcript lines:
        \(kept.isEmpty ? "None" : kept.map(MeetingPromptLines.line).joined(separator: "\n"))
        """
        return (CleanupRequest(system: systemPrompt, user: user, maxTokens: budget.outputTokens), newCutoff)
    }
}

/// Questions about the meeting that is being recorded.
public enum MeetingQuestion {
    public static let missedWindow: TimeInterval = 300
    public static let missedQuestion = "What was said in the last 5 minutes?"

    public static let systemPrompt = """
    Answer the user's question about a meeting that is still going on, using only the transcript lines \
    and the user's notes below. When the answer is not there, say that it was not said in the meeting so \
    far. Cite times as [m:ss]. Keep the answer short. Write in the language of the question.
    """

    /// - Parameter since: when set, only lines that end after this meeting time go in.
    public static func request(
        question: String,
        notes: String,
        segments: [MeetingSegment],
        since: TimeInterval? = nil,
        budget: MeetingTextBudget
    ) -> CleanupRequest {
        let notesText = String(notes.trimmingCharacters(in: .whitespacesAndNewlines).prefix(LiveSummaryPlanner.maxNotesCharacters))
        let lines = segments.filter { since == nil || $0.end > since! }.sorted { $0.start < $1.start }
        let room = max(0, budget.inputTokens * 3 - notesText.count - question.count - 200)
        let kept = MeetingPromptLines.newest(lines, maxCharacters: room)
        let user = """
        Transcript so far:
        \(kept.isEmpty ? "No lines yet." : kept.map(MeetingPromptLines.line).joined(separator: "\n"))

        My notes:
        \(notesText.isEmpty ? "None" : notesText)

        Question: \(question)
        """
        return CleanupRequest(system: systemPrompt, user: user, maxTokens: min(1_024, budget.outputTokens))
    }

    /// "What did I miss?": the last 5 minutes of meeting time before `now`.
    public static func missedRequest(
        notes: String,
        segments: [MeetingSegment],
        now: TimeInterval,
        budget: MeetingTextBudget
    ) -> CleanupRequest {
        request(question: missedQuestion, notes: notes, segments: segments, since: max(0, now - missedWindow), budget: budget)
    }
}

import AppKit
import ApplicationServices
import CoreAudio
import Foundation
import VoiceCore

/// Reads which processes use audio input, for meeting detection.
public enum AudioInputProcesses {
    /// Every process Core Audio lists, with its input flag. Browser processes
    /// that use input carry their browser's window titles (needs Accessibility).
    /// Throws when Core Audio cannot list processes.
    public static func current() throws -> [AudioInputProcess] {
        let system = AudioObjectID(kAudioObjectSystemObject)
        var address = AudioObjectPropertyAddress(
            mSelector: kAudioHardwarePropertyProcessObjectList,
            mScope: kAudioObjectPropertyScopeGlobal,
            mElement: kAudioObjectPropertyElementMain
        )
        var size: UInt32 = 0
        var status = AudioObjectGetPropertyDataSize(system, &address, 0, nil, &size)
        guard status == noErr else { throw MeetingAudioCaptureError.coreAudio(operation: "list audio processes", status: status) }
        var objects = [AudioObjectID](repeating: AudioObjectID(kAudioObjectUnknown), count: Int(size) / MemoryLayout<AudioObjectID>.size)
        status = AudioObjectGetPropertyData(system, &address, 0, nil, &size, &objects)
        guard status == noErr else { throw MeetingAudioCaptureError.coreAudio(operation: "read audio processes", status: status) }

        var titleCache: [String: [String]] = [:]
        return objects.compactMap { object in
            guard let pid = pid(of: object), let bundleID = bundleID(of: object) else { return nil }
            let running = isRunningInput(object)
            var titles: [String] = []
            if running, let app = MeetingDetector.appBundleID(for: bundleID), MeetingDetector.browsers[app] != nil {
                if let cached = titleCache[app] {
                    titles = cached
                } else {
                    titles = windowTitles(bundleID: app)
                    titleCache[app] = titles
                }
            }
            return AudioInputProcess(pid: pid, bundleID: bundleID, isRunningInput: running, windowTitles: titles)
        }
    }

    /// Titles of the app's windows through Accessibility; empty without permission.
    public static func windowTitles(bundleID: String) -> [String] {
        guard AXIsProcessTrusted() else { return [] }
        return NSRunningApplication.runningApplications(withBundleIdentifier: bundleID).flatMap { app -> [String] in
            let element = AXUIElementCreateApplication(app.processIdentifier)
            AXUIElementSetMessagingTimeout(element, 0.25)
            var value: CFTypeRef?
            guard AXUIElementCopyAttributeValue(element, kAXWindowsAttribute as CFString, &value) == .success,
                  let windows = value as? [AXUIElement] else { return [] }
            return windows.compactMap { window in
                var title: CFTypeRef?
                guard AXUIElementCopyAttributeValue(window, kAXTitleAttribute as CFString, &title) == .success else { return nil }
                return title as? String
            }
        }
    }

    private static func pid(of object: AudioObjectID) -> Int32? {
        var address = AudioObjectPropertyAddress(mSelector: kAudioProcessPropertyPID, mScope: kAudioObjectPropertyScopeGlobal, mElement: kAudioObjectPropertyElementMain)
        var value: pid_t = 0
        var size = UInt32(MemoryLayout<pid_t>.size)
        return AudioObjectGetPropertyData(object, &address, 0, nil, &size, &value) == noErr ? value : nil
    }

    private static func bundleID(of object: AudioObjectID) -> String? {
        var address = AudioObjectPropertyAddress(mSelector: kAudioProcessPropertyBundleID, mScope: kAudioObjectPropertyScopeGlobal, mElement: kAudioObjectPropertyElementMain)
        var value: Unmanaged<CFString>?
        var size = UInt32(MemoryLayout<Unmanaged<CFString>?>.size)
        let status = withUnsafeMutablePointer(to: &value) { AudioObjectGetPropertyData(object, &address, 0, nil, &size, $0) }
        guard status == noErr, let string = value?.takeRetainedValue() as String?, !string.isEmpty else { return nil }
        return string
    }

    private static func isRunningInput(_ object: AudioObjectID) -> Bool {
        var address = AudioObjectPropertyAddress(mSelector: kAudioProcessPropertyIsRunningInput, mScope: kAudioObjectPropertyScopeGlobal, mElement: kAudioObjectPropertyElementMain)
        var value: UInt32 = 0
        var size = UInt32(MemoryLayout<UInt32>.size)
        return AudioObjectGetPropertyData(object, &address, 0, nil, &size, &value) == noErr && value != 0
    }
}

import AppKit
import BugVoiceMac
import SwiftUI

/// Watches which apps use the microphone and offers to start or stop a
/// meeting recording. It never starts or stops one by itself.
@MainActor
final class MeetingDetectionController {
    /// Seconds between looks at the Core Audio process list.
    static let pollInterval: TimeInterval = 2

    private unowned let model: AppModel
    private var detector = MeetingDetector(ownPID: ProcessInfo.processInfo.processIdentifier)
    private var timer: Timer?
    private let popup = MeetingDetectionPopup()

    init(model: AppModel) {
        self.model = model
    }

    func start() {
        timer?.invalidate()
        timer = Timer.scheduledTimer(withTimeInterval: Self.pollInterval, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.tick() }
        }
    }

    func hidePopup() {
        popup.hide()
    }

    private func tick() {
        guard let meetings = model.meetings else { return }
        guard model.settings.meetings.detectMeetings else {
            popup.hide()
            return
        }
        let processes: [AudioInputProcess]
        do {
            processes = try AudioInputProcesses.current()
        } catch {
            // Detection stays off for this run; recording by hand still works.
            model.meetingDetectionUnavailable = true
            timer?.invalidate()
            timer = nil
            return
        }
        let recording = meetings.isRecording || meetings.isPaused
        if meetings.isActive, popup.kind == .detected { popup.hide() }
        let events = detector.update(
            processes: processes,
            now: Date(),
            isRecording: meetings.isActive,
            recordingApp: recording ? meetings.detected?.bundleID : nil,
            muted: Set(model.settings.meetings.mutedMeetingApps)
        )
        for event in events {
            switch event {
            case .detected(let candidate):
                popup.showDetected(
                    candidate,
                    onStart: { [weak self] in
                        self?.popup.hide()
                        Task { await self?.model.meetings?.start(detected: candidate) }
                    },
                    onMute: { [weak self] in
                        self?.popup.hide()
                        self?.mute(candidate.bundleID)
                    }
                )
            case .ended(let bundleID):
                guard recording, meetings.detected?.bundleID == bundleID else { continue }
                let name = meetings.detected?.appName ?? bundleID
                popup.showEnded(appName: name, elapsed: meetings.elapsed) { [weak self] in
                    self?.popup.hide()
                    Task { await self?.model.meetings?.stop() }
                }
            }
        }
    }

    private func mute(_ bundleID: String) {
        guard !model.settings.meetings.mutedMeetingApps.contains(bundleID) else { return }
        model.settings.meetings.mutedMeetingApps.append(bundleID)
    }

    /// The display that shows the frontmost app's front window, else the one with the pointer.
    static func frontmostWindowScreen() -> NSScreen? {
        if let pid = NSWorkspace.shared.frontmostApplication?.processIdentifier,
           let list = CGWindowListCopyWindowInfo([.optionOnScreenOnly, .excludeDesktopElements], kCGNullWindowID) as? [[String: Any]],
           let primaryHeight = NSScreen.screens.first?.frame.height {
            for info in list where (info[kCGWindowOwnerPID as String] as? Int32) == pid && (info[kCGWindowLayer as String] as? Int) == 0 {
                guard let bounds = info[kCGWindowBounds as String] as? NSDictionary,
                      let rect = CGRect(dictionaryRepresentation: bounds) else { continue }
                // Window bounds count from the top left of the primary display.
                let center = NSPoint(x: rect.midX, y: primaryHeight - rect.midY)
                if let screen = NSScreen.screens.first(where: { $0.frame.contains(center) }) { return screen }
            }
        }
        let mouse = NSEvent.mouseLocation
        return NSScreen.screens.first { $0.frame.contains(mouse) } ?? NSScreen.main
    }
}

import AppKit

/// Owns the meeting window: docked to the right third of the screen, above
/// other windows on every Space. Buttons and tabs do not take the keyboard
/// from the meeting app; the notes editor and the Ask box do.
@MainActor
final class MeetingWindowController: NSObject, NSWindowDelegate {
    static let autosaveName = "MeetingWindow"
    static let minWidth: CGFloat = 360
    static let minHeight: CGFloat = 420
    static let topBarHeight: CGFloat = 44
    static let inset: CGFloat = 12

    private let model: AppModel
    private let controller: MeetingController
    private var window: MeetingPanel?
    /// The height before Collapse, so expanding restores it.
    private var expandedHeight: CGFloat?

    init(model: AppModel, controller: MeetingController) {
        self.model = model
        self.controller = controller
    }

    func show() {
        let window = self.window ?? makeWindow()
        self.window = window
        applyCollapsed(animate: false)
        window.orderFrontRegardless()
    }

    func hide() {
        window?.orderOut(nil)
    }

    func toggleCollapsed() {
        model.settings.meetings.windowCollapsed.toggle()
        applyCollapsed(animate: true)
    }

    /// Right third of the visible frame, full height, 12 pt in from the edges.
    static func defaultFrame(on screen: NSScreen) -> NSRect {
        let visible = screen.visibleFrame.insetBy(dx: inset, dy: inset)
        let width = max(minWidth, (visible.width / 3).rounded())
        return NSRect(x: visible.maxX - width, y: visible.minY, width: width, height: visible.height)
    }

    private func applyCollapsed(animate: Bool) {
        guard let window else { return }
        var frame = window.frame
        if model.settings.meetings.windowCollapsed {
            window.contentMinSize = NSSize(width: Self.minWidth, height: Self.topBarHeight)
            guard frame.height > Self.topBarHeight + 1 else { return }
            expandedHeight = frame.height
            frame.origin.y += frame.height - Self.topBarHeight
            frame.size.height = Self.topBarHeight
        } else {
            window.contentMinSize = NSSize(width: Self.minWidth, height: Self.minHeight)
            guard frame.height < Self.minHeight else { return }
            let screen = window.screen ?? NSScreen.main
            let height = expandedHeight ?? screen.map { Self.defaultFrame(on: $0).height } ?? 700
            frame.origin.y -= height - frame.height
            if let visible = screen?.visibleFrame, frame.minY < visible.minY { frame.origin.y = visible.minY }
            frame.size.height = height
        }
        window.setFrame(frame, display: true, animate: animate)
    }

    private func makeWindow() -> MeetingPanel {
        let window = MeetingPanel(
            contentRect: NSRect(x: 0, y: 0, width: 440, height: 700),
            styleMask: [.titled, .resizable, .fullSizeContentView, .nonactivatingPanel],
            backing: .buffered,
            defer: false
        )
        window.title = "Meeting"
        window.titleVisibility = .hidden
        window.titlebarAppearsTransparent = true
        for button in [NSWindow.ButtonType.closeButton, .miniaturizeButton, .zoomButton] {
            window.standardWindowButton(button)?.isHidden = true
        }
        window.identifier = AppWindow.meeting
        window.level = .floating
        window.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]
        window.isMovableByWindowBackground = true
        window.isReleasedWhenClosed = false
        window.hidesOnDeactivate = false
        // Clicks on buttons and tabs leave the keyboard with the meeting app.
        window.becomesKeyOnlyIfNeeded = true
        window.delegate = self
        let hosting = NSHostingController(
            rootView: MeetingWindowView(
                model: model,
                controller: controller,
                onToggleCollapse: { [weak self] in self?.toggleCollapsed() },
                onClose: { [weak self] in
                    guard let self else { return }
                    self.hide()
                    Task { await self.controller.closeWindow() }
                }
            )
        )
        // The window's frame comes from the user and autosave, not the content.
        hosting.sizingOptions = []
        window.contentViewController = hosting
        let restored = window.setFrameUsingName(Self.autosaveName)
        if !restored || !Self.fitsAScreen(window.frame) {
            let screen = AppWindow.developmentScreen() ?? MeetingDetectionController.frontmostWindowScreen() ?? NSScreen.main
            if let screen { window.setFrame(Self.defaultFrame(on: screen), display: false) }
        }
        window.setFrameAutosaveName(Self.autosaveName)
        return window
    }

    /// True when most of the frame is on a connected display.
    static func fitsAScreen(_ frame: NSRect) -> Bool {
        NSScreen.screens.contains { screen in
            let overlap = screen.visibleFrame.intersection(frame)
            return overlap.width * overlap.height >= frame.width * frame.height * 0.5
        }
    }
}

/// Markdown notes editor with its own undo, Markdown styling, and Tab /

struct MeetingNotesEditor: NSViewRepresentable {
    @Binding var text: String

    func makeNSView(context: Context) -> NSScrollView {
        let editor = MeetingNotesTextView(frame: .zero)
        editor.delegate = context.coordinator
        editor.isRichText = false
        editor.importsGraphics = false
        editor.allowsUndo = true
        editor.font = MarkdownTextStyler.bodyFont

        editor.drawsBackground = false
        editor.textContainerInset = NSSize(width: 10, height: 12)
        editor.string = text
        editor.setAccessibilityLabel("My notes")

        let scroll = NSScrollView(frame: .zero)
        scroll.hasVerticalScroller = true
        scroll.borderType = .noBorder
        scroll.drawsBackground = false
        // A text view made with frame .zero stays 0 pt wide unless it grows with the scroll view.
        editor.minSize = .zero
        editor.maxSize = NSSize(width: CGFloat.greatestFiniteMagnitude, height: CGFloat.greatestFiniteMagnitude)
        editor.isVerticallyResizable = true
        editor.isHorizontallyResizable = false
        // Fills the pane, so a click below the last line still lands in the editor.
        editor.autoresizingMask = [.width, .height]
        editor.textContainer?.widthTracksTextView = true
        scroll.documentView = editor
        context.coordinator.editor = editor
        context.coordinator.restyle()
        return scroll
    }

    func updateNSView(_ scroll: NSScrollView, context: Context) {
        context.coordinator.text = $text
        guard let editor = scroll.documentView as? MeetingNotesTextView, editor.string != text else { return }
        let selection = editor.selectedRange()
        editor.string = text
        editor.setSelectedRange(NSRange(location: min(selection.location, (text as NSString).length), length: 0))
        context.coordinator.restyle()
    }

    @MainActor
    final class Coordinator: NSObject, NSTextViewDelegate {
        var text: Binding<String>
        weak var editor: MeetingNotesTextView?

            guard let editor else { return }
            text.wrappedValue = editor.string
            restyle()
        }

        func restyle() {
            guard let editor, let storage = editor.textStorage else { return }

import AppKit
import Foundation
import VoiceCore

enum MeetingSummaryState: Equatable {
    /// Before the first refresh, or between refreshes.
    case waiting
    case refreshing
    /// No Meetings model is set.
    case noModel
    /// The last refresh failed; the next one retries.
    case failed
    /// Writing the final summary after Stop.
    case finalizing
}

/// The answer card above the dock.
struct MeetingAnswer: Equatable {
    enum State: Equatable {
        case loading
        case done
        case noModel
        case failed(String)
    }

    var question: String
    var text: String
    var state: State
}

/// Live summary, Ask anything and the final summary for the meeting window.
extension MeetingController {
    /// Runs a live summary refresh when one is due. Called once a second while recording.
    func refreshLiveSummaryIfDue() {
        guard summaryTask == nil, isRecording, let session else { return }
        // Dictation goes first on the same model.
        guard model.dictation?.isBusy != true, !model.isListening else { return }
        guard LiveSummaryPlanner.isDue(
            activeTime: elapsed,
            lastRefresh: lastRefreshActiveTime,
            segments: segments,
            cutoff: liveSummaryCutoff,
            notesChanged: notes != notesAtLastRefresh
        ) else { return }
        let activeTime = elapsed
        let notes = notes
        let planned = LiveSummaryPlanner.request(
            previous: liveSummary,
            notes: notes,
            segments: segments,
            cutoff: liveSummaryCutoff,
            budget: MeetingTextBudget(settings: model.settings.meetings)
        )
        // A failed or skipped refresh waits for the next interval too.
        lastRefreshActiveTime = activeTime
        notesAtLastRefresh = notes
        summaryTask = Task { [weak self] in
            guard let self else { return }
            defer { self.summaryTask = nil }
            guard let textModel = await self.model.meetingTextModel() else {
                self.summaryState = .noModel
                return
            }
            self.summaryState = .refreshing
            do {
                let text = try await textModel.clean(planned.request).trimmingCharacters(in: .whitespacesAndNewlines)
                guard !text.isEmpty else {
                    self.summaryState = .failed
                    return
                }
                let now = Date()
                try? await session.setLiveSummary(text, updatedAt: now, cutoff: planned.cutoff)
                self.liveSummary = text
                self.liveSummaryUpdatedAt = now
                self.liveSummaryCutoff = planned.cutoff
                self.summaryState = .waiting
            } catch {
                self.summaryState = .failed
            }
        }
    }

    /// Asks about this meeting; nil asks "What did I miss?".
    func ask(_ question: String?) {
        let text = question?.trimmingCharacters(in: .whitespacesAndNewlines) ?? MeetingQuestion.missedQuestion
        guard !text.isEmpty else { return }
        askTask?.cancel()
        answer = MeetingAnswer(question: text, text: "", state: .loading)
        let budget = MeetingTextBudget(settings: model.settings.meetings)
        let request = question == nil
            ? MeetingQuestion.missedRequest(notes: notes, segments: segments, now: elapsed, budget: budget)
            : MeetingQuestion.request(question: text, notes: notes, segments: segments, budget: budget)
        askTask = Task { [weak self] in
            guard let self else { return }
            guard let textModel = await self.model.meetingTextModel() else {
                self.answer?.state = .noModel
                return
            }
            do {
                let reply = try await textModel.clean(request).trimmingCharacters(in: .whitespacesAndNewlines)
                guard !Task.isCancelled, self.answer?.question == text else { return }
                self.answer = MeetingAnswer(question: text, text: reply, state: .done)
            } catch {
                guard !Task.isCancelled, self.answer?.question == text else { return }
                self.answer?.state = .failed("Could not get an answer: \(error.localizedDescription)")
            }
        }
    }

    func closeAnswer() {
        askTask?.cancel()
        askTask = nil
        answer = nil
    }

    /// Appends the question and answer to My notes.
    func addAnswerToNotes() {
        guard let answer, answer.state == .done else { return }
        let separator = notes.isEmpty || notes.hasSuffix("\n\n") ? "" : notes.hasSuffix("\n") ? "\n" : "\n\n"
        notes += separator + "**Q:** \(answer.question)\n\n\(answer.text)\n"
        closeAnswer()
    }

    /// After Stop: the summary from the whole transcript, following the notes.
    func generateFinalSummary() async {
        summaryTask?.cancel()
        await summaryTask?.value
        guard let id = shownMeetingID, !segments.isEmpty else { return }
        guard await model.meetingTextModel() != nil else {
            summaryState = .noModel
            return
        }
        summaryState = .finalizing
        do {
            finalSummary = try await model.generateMeetingText(id: id, kind: .summary) { _ in }
            summaryState = .waiting
        } catch {
            summaryState = .failed
        }
    }
}

@MainActor
final class MeetingNotesInsertion: InsertionTarget, @unchecked Sendable {
    private weak var editor: MeetingNotesTextView?

    init(editor: MeetingNotesTextView) {
        self.editor = editor
    }

    func insert(_ text: String) async -> InsertOutcome {
        guard let editor, editor.window != nil else { return .notConsumed }

                    .allowsHitTesting(false)
            }
        }
        .background(Color.secondary.opacity(0.06), in: RoundedRectangle(cornerRadius: 8))
        .onAppear { draft = meeting.notes }
        .onChange(of: meeting.notes) { _, notes in
            if saveTask == nil { draft = notes }
        }
        .onChange(of: draft) { _, notes in
            guard notes != meeting.notes else { return }
            saveTask?.cancel()
            saveTask = Task {
                try? await Task.sleep(for: .seconds(1))
                guard !Task.isCancelled else { return }
                saveTask = nil
                await model.setMeetingNotes(id: meeting.id, notes: notes)
            }
        }
        .onDisappear {
            guard saveTask != nil else { return }
            saveTask?.cancel()
            saveTask = nil
            let id = meeting.id
            let notes = draft
            Task { await model.setMeetingNotes(id: id, notes: notes) }
        }
    }
}
