# BugVoice Meetings Implementation Plan

> **For agentic workers:** Follow tasks in order. Each task starts with a failing test, then implements the listed interfaces, runs `swift test`, and commits only after the suite passes.

**Goal:** Add local-first meeting recording with separate microphone/system tracks, live and final timestamped transcripts, playback, summary/action items, recovery, and retention.

**Architecture:** Keep every testable decision in Foundation-only `VoiceCore`: Codable meeting data, journal encoding/checkpoints, retention, chunk scheduling, priority, transcript filtering/merge, exports, timeline math, and long-transcript text generation. `BugVoiceMac` owns AVFoundation/Core Audio process-tap capture and AAC finalization. `BugVoice` wires the shared transcriber, menu, pages, non-activating recorder panel, permissions, and settings. One `WhisperKitTranscriber` instance is shared with dictation through a priority scheduler; meeting jobs yield at each approximately 30-second chunk.

**Tech Stack:** Swift tools 6.0, macOS 15+, SwiftUI/AppKit, AVFoundation, Core Audio process taps, Swift Testing, WhisperKit 1.1.1 exact. No new dependencies. `VoiceCore` imports Foundation only.

**Spec:** `docs/superpowers/specs/2026-10-14-meetings-design.md` (approved with maintainer amendments). Read it before Task 1.

## Global Constraints

- Never change dictation's default language, decoding mode, hotkey, HUD, or paste behavior. `TranscriptionOptions.timestamps` defaults to `false`; dictation remains forced-language and no-timestamps.
- Meeting timestamp mode uses `.auto`. Store requested and detected language per chunk. Forced `vi`/`en` retry uses no timestamps and VAD window start/end bounds.
- Dictation wins over queued meeting work. Never send a meeting track longer than about 30 seconds to the shared WhisperKit instance, including the final pass.
- Skip a meeting chunk only when no adjacent 100 ms window exceeds RMS `0.003`. Strip placeholders and run `HallucinationFilter` for every returned meeting chunk before merge/persistence.
- For silence gating, a 30-second chunk containing 29 seconds of silence and one second of speech must pass the gate.
- Capture separate headerless little-endian signed Int16 PCM journals, 16 kHz mono. Checkpoint data and manifest at least once per second. Final `mic.m4a`, `system.m4a`, and mixed `audio.m4a` use AAC.
- Do not add dependencies. Use `Scripts/build-app.sh` for the app build; it signs with `Bugler Local Dev`.
- Run `swift test` before every commit. Every commit ends with `Co-Authored-By: Codex <codex@openai.com>`.
- Keep Notes out of scope. Do not merge or push.
- For every code task, write its test first and run that task's filtered test before implementation; record the expected failing assertion or missing-interface compile error. Then implement, rerun the filtered test, and run the full `swift test` before committing. The documentation-only task uses `git diff --check`.

## Review Focus

1. **Dictation latency during meetings.** A dictation request must run before the next queued meeting chunk and wait behind no more than one in-flight meeting chunk. Pin ordering with a deterministic VoiceCore scheduler test.
2. **Timestamp decoding.** Normal meeting requests use `.auto` plus timestamps. Forced `vi`/`en` retry uses no timestamps and VAD window bounds. Do not enable timestamp decoding for dictation.
3. **Silence and Whisper hallucinations.** Silence below RMS `0.003` never reaches Whisper. Placeholder-only and exact HallucinationFilter phrases do not enter the transcript or live latest-line UI.
4. **Long meeting text.** Part splitting respects configured context/output budgets, preserves speaker/timing boundaries, merges all parts, reports progress, and cancellation leaves transcript/audio intact.
5. **Interrupted capture.** Only committed journal bytes are recovered; checkpoint byte offsets prevent a partial trailing sample from being decoded. Retention cannot delete active, interrupted, or transcribing meetings.

### Task 1: Meeting manifest and atomic persistence
