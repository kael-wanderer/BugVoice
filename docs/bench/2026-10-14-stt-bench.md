# STT and cleanup benchmark — 2026-10-14

## Decision: gate open, default language stays `auto`

Run on the maintainer's M3 Ultra, WhisperKit `large-v3-v20240930_turbo`,
LM Studio `qwen3.8-27b-mlx`. Four of six clips recorded; only `en-1` has a
reference transcript, so no WER on `mix-*` and the decision rule cannot run.

Findings:
- **Decoder bug, fixed.** WhisperKit 1.1.1 returned empty text whenever a
  forced language (prefill prompt) was combined with timestamp decoding: every
  `vi` row was empty. The transcriber now decodes without timestamps. Verified
  with a 48-run option matrix (language × VAD chunking × prefill × timestamps).
- **`en-1` and `vi-1` are not usable.** Normal levels (mean −25 dB) and no long
  silence, yet every decode option hears music ("*Bad music*", "*Sings*") or
  produces a stock hallucination. Re-record from the built-in microphone with
  no audio playing.
- **`auto` translates.** On `mix-1` (Vietnamese opening, English rest),
  `auto` rendered the Vietnamese clause as English ("Why today I am going to
  test this?"); forced `vi` kept it as Vietnamese ("Vì sao hông nay mình lại thay test này?")
  in the option matrix, but returned empty in the run below. Forced `vi` drops
  English-heavy audio as no speech, so it is not yet a safe default.
- **Cleanup is too slow.** 19–24 s per clip, and most outputs are empty:
  LM Studio ignores the request-side thinking switch, and reasoning consumes
  the token budget. Target is 2.5 s median. Turn thinking off in LM Studio's
  model settings or pick a smaller non-thinking model, then re-run.

To close the gate: record `en-2`, `vi-2`, re-record `en-1`, `vi-1`, write a
`.txt` reference for every clip (exact words, with diacritics), fix cleanup
latency, and re-run `Scripts/stt-bench.sh`.
