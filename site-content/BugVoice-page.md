## FAQ

**1. What is BugVoice?** `17/120`

BugVoice is a menu bar app for macOS that turns speech into clean text. Hold Right Control, speak and release; the text is pasted at your cursor in any app. It also records and transcribes meetings, keeps notes in a floating Scratchpad, and shows stats about how much you dictate. `280/600`

**2. Who is it for?** `14/120`

People who write all day on a Mac and would rather talk: developers prompting coding agents in a terminal, people answering email and chat, and anyone who takes meeting notes. It handles English, Vietnamese and Spanish, including sentences that mix English technical words into Vietnamese or Spanish. `300/600`

**3. What do I need to run it?** `25/120`

A Mac with Apple Silicon (M1 or later) running macOS 15 Sequoia or later. The default speech model is a 1.6 GB download on first use; a 0.5 GB model is available for smaller Macs. For text cleanup you need a local model server such as oMLX, LM Studio or Ollama, Apple Intelligence, or an API key for a cloud model. Without one, BugVoice pastes the raw transcript. `363/600`

**4. How much does it cost?** `22/120`

PRICE AND LICENCE: to be confirmed by the owner before publishing. `66/600`

**5. Where is my data stored? Does anything go to the cloud?** `55/120`

Everything is stored in ~/Library/Application Support/BugVoice on your Mac: settings, history, notes (Markdown files), meetings and their audio. Speech recognition runs on your Mac. Text is sent only to the text model you configure; if that is a local server, nothing leaves your Mac. API keys are kept in a file only your user can read. The app downloads speech models from Hugging Face once. `393/600`

**6. Does it sync between Macs or work offline?** `42/120`

There is no sync and no account. With a local text model, dictation and meetings work fully offline once the speech model is downloaded. To move your library, use Settings, Storage, Backup to write an archive to any folder, then Restore it on the other Mac. `257/600`

**7. How do I install and update it?** `31/120`

Download the DMG and drag BugVoice to Applications. The app is not notarized by Apple, so the first time macOS blocks it: open System Settings, Privacy & Security, and click Open Anyway. BugVoice then asks for Microphone, Accessibility and Input Monitoring so it can hear you, paste text and see the hotkey. To update, replace the app with the new version; your library stays where it is. `388/600`

**8. Can I import audio or export my meetings and notes?** `51/120`

Yes. The Upload page transcribes MP3, WAV, M4A, AIFF, CAF, MP4, MOV and M4V files into a meeting with timestamps. Each meeting can be exported as Markdown, SubRip captions or audio. Notes are plain Markdown files you can open in any editor. `240/600`

**9. How is it different from macOS Dictation?** `41/120`

macOS Dictation types what you say. BugVoice also cleans up fillers and self-corrections, adapts the tone to each app, learns your words, keeps a searchable history, and adds meeting recording with summaries and action items. You choose the speech and text models. `264/600`

**10. Can coding agents use it?** `25/120`

BugVoice can run an MCP server that lets agents such as Claude Code read and search your notes and meetings, create notes and upload recordings. It is off by default; turn it on in Settings, Agents, where you also choose whether agents may edit notes or upload files. `267/600`

**11. How do I report a bug?** `22/120`

BUG REPORT CHANNEL: to be confirmed by the owner. Settings, Storage, Copy diagnostics copies the app version, model names and this session's log (never your dictated text) so you can paste it into a report. `206/600`
